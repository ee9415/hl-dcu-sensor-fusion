# 1차 우선 적응 차수 중심선

작성일: 2026-10-16

## 변경 및 판단 기준

oakapp 0.9.0. 기존 원시 점선/한쪽 확장 억제 뒤에 AdaptiveOrderSelector를 추가했다.
입력 3차식의 유효 거리 내 80개 표본을 1/2/3차 후보로 다시 근사하고 최소 차수를 우선한다.
원시 점선 자체를 다시 학습하는 것이 아니며, 낮은 차수 근사는 점선과 일부 차이가 난다.

- 초기 선택 차수는 1. c0와 c1을 피팅하며 c2=c3=0이다. c0를 0으로 고정하지 않는다.
- 1차 RMS 오차 >0.25, 높은 차수의 개선 >0.10이 0.4초 지속되면 2차로 승격한다.
- 2차 RMS 오차 >0.35, 3차 개선 >0.10이 0.8초 지속되면 3차로 승격한다.
- 대칭 S곡선은 2차 개선이 없을 수 있으므로 1차에서 전체 고차 개선을 확인하되
  2차 단계를 거친 후 3차를 허용한다. 1차에서 3차로 직접 건너뛰지 않는다.
- 한 단계 낮은 차수 오차 <0.12가 1초 지속되면 한 단계 내린다.
- 차수 전환 중 시간 필터를 사용하며 추가 속도 제한은 최대 0.6초로 한정한다.
  초기 구현의 무제한 전환 제한이 실영상에서 추종 지연을 일으켜 이 상한을 추가했다.
- 차수 하향 시 고차항을 서서히 줄이고 곡선 영향이 0.01 미만이면 정확히 0으로 만든다.
- 시간 필터의 가시 범위 복구 피팅도 필요한 차수만 사용한다. 따라서 1차 상태에서
  거리 범위가 변했다고 자동으로 3차항이 생기지 않는다.
- 근사 곡선이 현 프레임 경계 안에 90% 이상 포함되지 않으면 무효 측정으로 처리한다.
  초기 직선이 부적절한 장면에서 직선을 강제로 안전한 경로처럼 표시하지 않는다.
- 입력 공백 >0.5초는 선택 차수를 1로 초기화한다. 역순 입력과 미관측은 거부한다.

오차/거리/속도 제한은 기존 고정 호모그래피의 개발용 BEV 단위다. 실제 미터값으로
검증된 차량 제어 파라미터가 아니다. 고차항 사용 억제는 차수 선택으로 구현했다.

## 검증

Ubuntu unittest 36개 통과, Python 문법 검사 및 git diff --check 통과.
추가 테스트: 직선의 정확한 고차항 0, 2차 필요성 지속 확인, S곡선의 순차 승격,
한 프레임 이상치 승격 방지, 3→2→1 복귀 및 고차항 소거, 공백/역순/미관측,
차수 전환 제한이 장시간 추종 정체로 남지 않는지 확인.
독립 카메라 후처리 변경으로 ROS2 topic/TF/namespace는 변경하지 않았다.

## 실영상

OAK가 모니터의 도로 영상을 촬영하는 환경에서 배포·녹화·시각 확인했다.
최종 영상: artifacts/centerline_adaptive_order_final/result.mp4.

- 30.062초, 292프레임. 연결 성분 분석 미검출 0프레임.
- 같은 행의 선 위치 변화: 95백분위 8px, 최대 48px. 최대값이 남아 있으므로
  완전히 부드러운 주행 경로라고 보증하지 않는다. 압축/색상 검출 오차가 포함될 수 있다.
- 5초 간격 6개 표본에서 중심선 표시가 이어짐을 직접 확인했다.
- 로그에서 2차 c3=0, 3차 사용, 다시 1차 c2=c3=0 복귀를 확인했다.
  예: 01:31:24 UTC 계수 [1.115714, -0.075031, 0, 0].
- 01:30:59~01:31:14 UTC의 4개 창은 202/202 유효,
  출력 차수별 1차 0/2차 138/3차 64프레임이었다.
- 이어진 01:31:19~01:31:35 UTC의 4개 창은 202/202 유효,
  1차 159/2차 43/3차 0프레임으로 낮은 차수 복귀를 확인했다.
- 더 긴 관측에서는 01:31:40 UTC 창이 51프레임 중 39 유효였다. 따라서
  최종 30초 무소실 결과를 이후 모든 장면에 일반화하지 않는다.
- RGB/YOLO/BEV 멀티뷰 수신 및 ImageTk 미리보기 검사 통과.

## 미확정/주의

자연스러움은 위 표본과 통계에 한정한 평가이며 추가 도로 영상 검증이 필요하다.
과거 영상과 동일 프레임 재생 비교가 아니므로 개선율은 산출하지 않는다.
실제 차속/요레이트 보상, 카메라 외부 보정, 경계/장애물의 정답 비교와 차량 조향 검증은
수행하지 않았다. 저차식 선택은 잘못된 주행 가능 마스크 자체를 교정하지 못한다.
