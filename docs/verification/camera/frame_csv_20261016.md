# 프레임별 CSV 로깅 — 2026-10-16

## 변경

oakapp 0.14.0은 TCP 8557에서 처리 프레임별 JSON을 출력한다. PC 멀티뷰는
영상 연결 시 자동으로 frames.csv 및 objects.csv를 생성한다. 영상 녹화 버튼과
독립적이며 창 종료까지 기록한다. UI에 경로, 성공적으로 flush한 프레임/객체
행 수, 시퀀스 누락, 연결/저장 상태를 표시한다. 매 프레임 flush하지만 fsync나
두 파일 간 트랜잭션은 아니므로 전원 차단 시 마지막 행 보존은 보장하지 않는다.

각 파일은 session+frame_seq로 연결한다. 객체 번호는 프레임 내 인덱스이며 추적 ID가
아니다. 무효 Depth는 빈 거리값, 무효 중심선은 빈 계수로 남긴다. 객체가 없는
프레임도 frames.csv에 저장한다. XYZ는 카메라 광학 좌표계 m, Z는 광축 방향 거리.
중심선 계수는 보정되지 않은 BEV 개발 단위이며 선회 미리보기 경로 계수가 아니다.
카메라가 모니터를 촬영하면 거리는 모니터까지의 거리이다.

## 수신 지연 정의

촬영 프레임 타임스탬프에서 구조화 데이터 PC 수신까지의 추정 지연이다.
RTSP 영상 디코딩/화면 표시 지연 또는 실제 노출 시각의 정밀 측정은 아니다.
장비와 PC의 단조 시계를 5초마다 왕복 교환으로 비교하여 offset을 추정한다.
UTC 시각은 별도 기록한다. 초기 벽시계 차감 실험에서 음수값이 발견되어 단조 시계
방식으로 보완했다. 음수/큰 RTT/물리적으로 부적합한 결과는 invalid 상태와 빈 추정값으로
기록하고 원시 계산값을 보존한다. 네트워크 비대칭/드리프트 영향은 남으며 PTP 정확도는 아니다.

유효 지연 추정 평균 99.52ms, 범위 71.53~145.30ms. 175행은 시계/비대칭 검사를
통과하지 못해 지연 무효로 저장했다. 유효 표본만의 통계이며 전체 구간 지연 성능을
대표한다고 볼 수 없다. WSL/장비 시간 안정성 및 정밀 동기화는 추가 검증 필요.
프로그램이 계속 기록하므로 이후 파일 행 수는 증가한다.

ROS 수신기가 아니라 멀티뷰의 직접 TCP 수신기이다. ROS 토픽/TF/드라이버는 변경하지 않았다.
colcon/ROS launch 검증은 이번 변경 범위 밖이다. TCP 포트는 인증/암호화 없는 읽기 전용
데이터 출력이므로 신뢰하는 내부망에서만 사용한다. 100프레임 큐 초과 시 오래된 항목을
버리고 시퀀스로 누락을 표시한다. 연결 전/첫 프레임 이전의 손실은 누락 합계에 포함되지 않는다.
자동 파일 회전/용량 정리/단절 중 장비 내 저장/재전송은 구현하지 않았다.
