# Depth 표시 범위 변경 — 2026-10-18

## 변경 근거

사용자 요청에 따라 색상 표시 최대 거리를 10m에서 25m로 변경했다.
빨강 0.3m~파랑 25m의 고정 로그 스케일이며 무효값은 검정이다.
25m 이상은 파랑으로 포화된다. 거리 측정 파이프라인과 원본 mm 값,
객체 XYZ 산출, ROS 토픽/TF/드라이버는 변경하지 않았다.

## 제한

실제 25m 위치의 정답 대상을 사용한 거리 정확도 검증은 수행하지 않았다.
표시 범위 변경은 유효 측정 범위 자체를 늘리지 않으며 검정 무효 영역을 복원하지 않는다.
기존 실행 창의 제목 범례는 유지될 수 있으므로 새로 실행한 25m 범례 창을 사용한다.
ROS 빌드/launch 검사는 standalone 표시 범위 변경에 해당하지 않아 수행하지 않았다.
