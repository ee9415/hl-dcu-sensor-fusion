# OAK4 YOLOPv2 기준 코드 이관 검증 기록

- 검증일: 2026-10-15
- 대상 장비: OAK 4D Pro RVC4
- 검증 범위: 임시 프로젝트 기준 코드의 정식 저장소 이관
- 정식 경로: `apps/yolopv2_standalone`, `tools/oak_recorder.py`

## 1. 검증 방법

1. 임시 `D:\git_hub\OAK_4D_PRO` 프로젝트와 정식 저장소의 이관 대상
   13개 파일을 SHA-256으로 비교했다.
2. 로컬 배포용 `yolopv2_320.rvc4.tar.xz`의 원본·이관본 SHA-256을
   비교했다.
3. Python 표준 `py_compile`로 이관한 Python 소스의 문법을 검사했다.
4. `git check-ignore`로 모델 압축파일이 Git 추적 대상에서 제외되는지
   확인했다.

## 3. 미수행 및 제한 사항

- 현재 시스템 Python에는 `numpy`, `opencv-python`, `depthai`가 설치되어 있지
  않아 후처리 함수와 녹화 UI의 런타임 import 검증은 수행하지 못했다.
- 임시 프로젝트의 Python 3.11 가상환경 실행 파일은 이 환경에서 비정상 종료되어
  검증에 사용하지 않았다.
- 이번 단계는 기존 동작 보존 목적의 코드 이관이다. OAK 장비 실행, RTSP 수신,
  녹화, 추론 FPS는 이 단계에서 다시 실측하지 않았다.
- RGB 정렬 Depth, 객체 거리, 가상 중심선은 아직 구현하지 않았다.

## 4. 판정

정식 저장소의 기준 코드는 임시 프로젝트 원본과 바이트 단위로 동일하며 정적 문법
검사를 통과했다. 다만 실제 OAK 4D Pro 장비 동작은 후속 단계에서 장비별로 다시
검증해야 한다.
