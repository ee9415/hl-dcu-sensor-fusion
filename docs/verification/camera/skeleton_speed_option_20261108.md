# 스켈레톤 반응 속도 앱 옵션 (2026-11-08)

## 변경 근거와 동작

사용자가 영상에 맞춰 반응 속도를 조절하도록 표시 설정에 0.5~3.0배 슬라이더와 숫자 입력을 추가했다. 1.0배는 0.33.7의 기본 응답이다. 적용 버튼, 슬라이더 놓기, 숫자 입력 후 Enter로 변경한다. full 모드에서 검출선 보정과 미검출 유지선의 반대편 커브 반영에 모두 적용한다.

기준 설정의 이동 속도 제한에 배율을 곱하고 시간 상수는 배율로 나눈다. 매번 원본 설정으로부터 계산하므로 배율 변경이 누적되지 않는다. 이상 관측 배제 및 차선 쌍 검증은 유지한다. 속도 변경은 영상 소스·처리 epoch나 추적 객체를 초기화하지 않는다. 프레임 메타데이터에 적용 배율과 별도 설정 epoch를 남긴다.

연결 중에는 장치 확인 응답 후 설정 파일에 저장하며 실패하면 이전 확인 값으로 복구한다. 미연결 상태에서는 저장 후 다음 영상 연결에 적용한다. 기존 설정에 항목이 없으면 1.0배를 사용한다. 카메라 부팅 기본값도 1.0배이며 앱이 연결할 때 저장한 값을 전달한다.

## 검증

- Python 구문 검사 통과.
- WSL 회귀 테스트 381개 통과 (61.445초).
- 설정 저장·기존 설정 호환·잘못된 배율 검증 6개 재실행 통과.
- 배율 계산, 제어 소켓 응답, 소스 epoch 유지, 과거 프레임 메타데이터 보존 검증 포함.
- 카메라 패키지 및 실시간 반영 확인: 배포 후 기록 예정.

ROS 드라이버·토픽·TF 변경이 없는 독립 OAK 앱/PC UI 수정으로 colcon/ROS 실행 검증 대상은 아니다. 영상별 최적 배율은 현장 조절 사항이다.
