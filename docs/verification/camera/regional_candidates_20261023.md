# 독립3구간 경계 후보 검출

날짜:2026-10-23, 앱0.32.0, 카메라192.168.201.2.

## 구현

320×180 축소영상 하단60%에서 겹치는 상/중/하 구간72~124/100~160/136~178행을
독립 탐색한다. 화면 끝2행은 제외한다. 표시 격자는 기존78~172행48점을 유지한다.
각 구간 최대24개 seed,4개 선분 후보로 제한한다. 짧은 선분은3점/4px부터 후보가
될 수 있으나 서로 다른 구간을 결합할 때 총10점/20px 이상을 요구한다.

2~3구간 조합의 끝점 방향 연속성과2차식 최대잔차2px를 검사한다. 중단 후보가 없어도
상/하단 조합을 평가한다. 선택된 모델과 기존 검출을 비교해 품질이 높은 결과를 사용한다.
겹치는 동일 근거를 두 독립 선분으로 중복 인정하지 않는다.

선택된 후보 사이의 빈 구간은2차식으로 연결하되 관측 support에는 실제 선분 행만
표시한다. 보간된 빈 구간은 관측 신뢰도/폭 학습의 근거가 아니다. 좌우는 각각 하나의
2차식이며 기존 교차/형상/보정속도 제한을 유지한다. 중심선 없음.

## 테스트

전체63개 테스트 통과. 신규시험은 중단 전체 소실에서도 상/하단 연결, 빈 구간의
관측표시 제외, 방향이 반대인 위쪽 선분 연결 거부를 검증한다. 기존 가로등/차량 제외/
밝은 노면/단일2차식 시험도 통과했다.

구간 내 후보 탐색은 짧은 국소 추적을 사용하지만 구간 사이 성공 여부에는 의존하지
않는다. 상단 단독 후보까지 항상 새 경계를 초기화하는 정책은 아니며, 독립 조합이
불충분하면 기존 검출/유지로 돌아간다.

## 검증 범위

초기 배포30초302프레임10.001FPS/누락0/무효쌍0/중심선0.
그러나 현재 장면에서 구간 결과 선택0건으로, 이를 영상 연결 개선이라고 주장하지 않았다.
구간 경계 조각을 포함하도록 겹침 범위를 넓히고 국소 후보 최소길이를 조정한 최종본을
다시 배포했다. 최종 측정은 아래에 별도 기록한다.

최종 배포본: 30초 301프레임, 처리 10.00125 FPS, source 누락0, 무효쌍0,
중심선0. 왼쪽 OBSERVED293/PARTIAL1/ALIGNING7, 오른쪽 PARTIAL301.
독립 구간 결과가 최종 선택된 횟수는 왼쪽1/오른쪽0이다. 따라서 실제 장면의
오른쪽 위쪽 흰색선 연결 개선은 확인되지 않았으며 문제 해결로 판정하지 않는다.
5초 수집은 RGB5장/결과8장/telemetry50건이며 영상 일부에 압축 깨짐이 있다.
처리 FPS와 영상 디코딩 수신률은 별개다.

원본 측정: artifacts/regions_0320_final_fps/report.json 및 동일 폴더 telemetry,
영상: artifacts/regions_0320_final_video/. 이 자료는 로컬 보관이며 커밋에서 제외했다.

현재 입력은 정지 장면이고 수신 영상에 일부 압축 깨짐이 있다. 실제 이동 커브와
모든 순간의 튐 검증은 별도 필요하다.
