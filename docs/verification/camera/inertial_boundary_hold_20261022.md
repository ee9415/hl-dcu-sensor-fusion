# 장기 경계 유지·영상 관성 (2026-10-22)

## 변경

0.24.0의 warp는 영상 밖 표본을 NaN으로 버려 매 프레임 지지 구간이 줄었고,
결국 관측이 오래 없으면 좌우 경계가 사라졌다. 0.25.0은 전체 곡선을 저장하고
다음 프레임의 전체 추적 행에 재표본화한다. 화면 안 지지가 거의 없어진 변환은
마지막 선을 유지한다. 관측이 부족하다는 이유만으로 곡선 이력을 삭제하지 않는다.

이동량을 시간으로 나눈 영상 움직임 속도를 0.25초 시정수로 평활한다.
움직임 자체가 불확실하면 0.6초 감쇠, 양쪽 흰색선 소실 시 1.5초 감쇠를 적용해
장기 드리프트를 줄이며 마지막 형상에 수렴시킨다. 차량 IMU/속도/조향각은 사용하지 않는다.
보이는 반대편과 학습된 영상 간격으로 누락 측을 최대3픽셀/프레임씩 보정한다.
한쪽만 최초 관측한 경우에는 원근 형태의 영상 간격을 낮은 신뢰도로 사용한다.
이는 물리 폭2.1m나 하단 고정점이 아니다. 양쪽 관측 후 영상 간격을 점진적으로 갱신한다.
재검출은 기존 전체 곡선 보간의 보정 제한을 유지하며 ALIGNING/OBSERVED를 구분한다.
가시 길이 부족으로 초기 관측이 안 되던 경우를 위해 최소 지지20픽셀/10관측행으로 조정했다.

## 한계

관성은 영상에서 추정한 움직임의 연속성을 뜻하며 실제 차량 동역학 보정이 아니다.
추정선을 유지하는 것은 실제 차선 위치나 주행 가능 공간을 보장하지 않는다.
한 번도 어느 쪽도 관측되지 않은 최초 상태, 명백한 장면 전환, 시간 역행/1초 초과 입력 단절은
초기화 대상이다. 잘못된 장면의 선을 영구히 유지하지 않는다.
짧은 관측의 외삽 및 초기 반대편 영상 간격은 오차가 클 수 있고, 장기 추정 신뢰도는 계속 감소한다.
고정 BEV는 참고 화면일 뿐이며 실제 거리 검증에 사용하지 않는다.
