# ROS 후처리 도로 녹화 영상 전체 재생 검증 (2026-11-24)

## 결과

카메라 추론→원본 데이터 전송→ROS 경계/정지선/안내 경로 계산→영상 저장의
전체 경로는 끝까지 동작했다. 인식 품질에서는 현재 관측보다 추정/유지 경계에
의존하는 비중이 높고, 양쪽 미관측 상태에서 추정 안내선이 오래 남는 문제가 확인됐다.
이 결과는 정답 라벨과 비교한 정확도 수치가 아니다.

- 실제 OAK4 169.254.100.228에서 YOLOPv2 추론, WSL Humble의 두 ROS 노드에서 후처리.
- 코드 release e9f2f1d52d6ed026ba238ea9ca6bf52a9c154d79f3ea88de38461adb89fd7396.
- 카메라 원본 전송 상한5FPS. 실제 ROS 샘플은 약3.86FPS이며 원본10FPS 전체를
  ROS에서 처리한 것은 아니다. 카메라로 보낸 9,845프레임은 모두 수신/소비됐다.
