# 현재 PC 영상 차선 점수 분포 측정 (2026-11-02)

## 결과

현재 사용자가 재생 중인 KakaoTalk_20261016_170026655.mp4의 원본 영상 시간
447.576~467.478초(약07:27.6~07:47.5)에서 200프레임, 실시간20.04초 측정했다.
원시 모델 내용 영역320×180에서 점수0.50 이상인 픽셀을 분모로 삼는다.

| 점수 구간 | 누적 픽셀 관측 수 | 비율 |
|---|---:|---:|
| 0.50 이상, 0.90 미만 | 18,148 | 8.78% |
| 0.90 이상, 1.00 이하 | 188,591 | 91.22% |
| 합계 | 206,739 | 100% |

프레임별 고점수 비율 최솟값67.39%, 중앙값91.71%, 최댓값97.18%.
모델 차선 픽셀이 전혀 없는 프레임은 없었다. 누적 픽셀 관측 수는 각 프레임의
관측을 합친 것으로 물리적 도로의 고유 픽셀 수가 아니다. 전체 비율은 프레임별
비율의 단순 평균이 아니라 누적 고점수 픽셀/누적 차선 픽셀이다.

## 방법

- 새 계측 코드 배포나 카메라 재시작 없이 기존 텔레메트리를 사용했다.
- 표시 설정만 일반0.90으로 잠시 변경했다. 같은 프레임의
  lane_perception_pixels(원시 인식 임계값0.50)와
  lane_preview_selected_pixels(표시 임계값0.90)를 비교했다.
- 새 표시 epoch가 적용된 PC 프레임만 사용하고 source epoch가 바뀌면 중단한다.
  nn_seq와 입력 프레임 식별자로 중복을 제외했다.
- 원시 점수 취득 오류 없음, 모든 프레임에서 0≤고점수수≤차선수 확인.
- 모델·영상 입력·후처리 계산은 변경하지 않았고, 종료 시 표시 일반0.50 복원.
  source/processing epoch 유지, PC publisher 연결 유지 확인.

측정 결과는 현재 영상의 해당20초 구간에 한정된다. 실제 차선 정답 주석이 없으므로
91.22%는 검출 정확도나 차선일 확률이 아니다. 오검출된 균열·연석 등도 모델이
점수0.50 이상으로 선택했다면 집계에 포함된다. 이번 분포는 두 구간 집계이며
0.90~1.00 내에서 점수가 얼마나 동일한지는 이 결과만으로 알 수 없다.
