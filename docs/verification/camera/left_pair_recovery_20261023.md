# 좌우 경계 중복 배정 및 좁은 이력 복구 0.33.0

## 변경

- 좌우 선택 곡선이 부적절한 쌍이면 낮은 신뢰도 쪽의 독립 구간 후보를 재평가.
- 실제 짧은 조각(6점/10px부터 후보, 표시격자8행 이상, 직선잔차1.5px 이하)을
  반대편과 함께 검사. 3회 연속/좌표차3px 이내인 경우 PARTIAL(0.5)로 채택.
- 같은 물리선을 좌우에 배정한 쌍 대신 반대편과 충분히 떨어진 후보만 선택.
- 붕괴한 이력은 해당 쪽의 위치 보정 기준에서 제외하고 실제 관측 범위로 재초기화.
  이 경우 즉시 위치 변화가 가능하다. 정상 쌍은 기존 속도 제한을 유지한다.
- 표시 이력과 last_valid_pair 분리. 후자는 복원되지 않은 양쪽OBSERVED/점수0.5이상만 저장.
- 기본 최소간격은 가까운 y>=150에서 원근형기준폭의25%, 먼 구간은 기존6px 기준.
  학습폭이5회 이상 있는 행은 학습폭55% 이상 요구. 원근형 기본폭은 실측m가 아니다.
  BoundaryConfig.image_min_width_ratio/.image_retained_width_ratio로 조정 가능.
- 약한/미검출 이력에서 독립 full검출 후보를3프레임 검증해 재획득.
- 기존 시간/장면변화 초기화 때 조각누적/재획득 상태도 함께 초기화.
  가림 전용 영상 분류기를 추가한 것은 아니다.
- 굵은 관측/옅은 전체 경계 표시, 단일2차식, 중심선 제외 유지.

## 회귀

70개 전체 테스트 통과. 실제 camera paint와 잘못된 prior를 fixture로 고정.
12회 재생 후 실제 왼쪽 위치로 복귀하고 좁은 쌍 거부, PARTIAL로 정상 이력/폭 학습
오염 방지 확인. 기존 주차차량/가로등/커브/시간보정/좌우보호 시험 통과.
최초 최소폭을 먼 구간에까지 적용한 회귀를 수정하여 기존 fixture도 유지했다.
