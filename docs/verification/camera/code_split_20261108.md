# 실행 환경·코드 분리 배포 검증 (2026-11-08)

## 목적 및 변경

일반 기능 수정마다 약 1GB 전체 이미지를 재전송하던 방식을, 고정 실행 환경 컨테이너와 앱 전용 영구 저장소의 코드 릴리스로 분리한다. 최초 실행 환경 0.33.10부터 고정 런처를 사용한다. 이후 동일 라이브러리 계약의 Python/JSON 변경은 작은 ZIP만 전달한다. 라이브러리·모델·런처 변경 시에는 전체 패키지를 갱신한다.

전송 완료 후 해시·경로·크기·구문·JSON·실행 환경 계약을 검사한다. 단계별 코드 폴더와 atomic state 파일로 전환하며, 새 버전의 full 프레임 확인 후 확정한다. 기동 실패 또는 확정 전 중단은 이전 정상 코드/embedded 코드로 복구한다. 예전 버전과 앱은 삭제하지 않는다.

공식 저장소 의미와 실제 mount를 확인했다. `OAKAGENT_STORAGE_APP=/app-storage/app`은 앱 UUID 전용 영구 저장소다. 같은 UUID의 컨테이너 재시작을 보존 대상으로 삼고, 다른 UUID로 설치하거나 앱을 삭제하는 상황을 자동 승계 대상으로 삼지 않는다.

## 검증 결과

- WSL 회귀 388개 통과 (62.452초). 신규 7개는 실행 환경 불일치·손상 ZIP/경로·코드 묶음 분리·재열기·수동 복구·기동 실패 자동 복구·확정 전 중단·정상 확정을 검증한다.
- Python 구문 검사 통과. ROS 토픽·TF·드라이버 변경이 없는 배포 도구/독립 앱 변경으로 ROS 실행 검증 대상은 아니다.
- 추가 단위 검증 9개 통과. oakctl이 oakapp.toml을 컨테이너에서 제외하는 경우와 기본 이미지 설정 불일치를 검사한다. 초기 0.33.9 장치 기동 검증에서 이 제외 동작을 확인하고 해당 앱을 중지한 뒤 0.33.8로 복구했다. 0.33.10에서는 별도 runtime-base.toml을 포함한다.
- 현재 코드 ZIP 크기 82,217bytes. 모델·라이브러리·테스트·런처 제외.
- 장치 검증 결과는 최초 실행 환경 설치 후 기록한다.

## 운영

[분리 배포 매뉴얼](../../operation/camera_code_deployment.md)을 따른다. 컨테이너 버전과 코드 release SHA256을 구분한다. 배포 기록은 `artifacts/code_split_20261108`에 보관한다. 정상 프레임 검사는 기동 확인이며 인식 정확도 회귀 검사를 대체하지 않는다.
