# 급격한 곡률 변경 확인 및 양쪽 관측 보존 (2026-11-10)

## 요청과 원인

사용자는45초 부근 오른쪽 급격한 휨을 보고, 이전 차선을 유지하다 여러 프레임에서 확인된 변경만 반영하도록 요청했다. 최종 모델과 분홍 표시는2차식을 유지한다. 추가 첨부의 처리 시각은 약378초와428초이며 UI 전송 위치와 구분한다.

code10 실장치0~70초 기록에서45.3초 오른쪽 prior_error_px는0.912로 정상 통과했지만2차항은0.00280,46.6초에는0.01126으로 증가했다. 오차는 현재 관측 행에서만 검사했고, 짧은 관측의2차식을 기존 긴 표시 범위로 외삽하는 곡률 변화는 따로 검사하지 않았다. 저장된 FP32 원본 마스크 재현에서 횡단보도·정지선과 합쳐진 마스크 및 짧은 오른쪽 근거리 관측을 확인했다. FP32 재현은 장치 FP16 마스크와 동일하다고 간주하지 않는다.

기존 weak 조건은 두 관측의 품질·지지 수·이전 오차를 합친 점수가15%만 차이나도 약한 쪽을 추정선으로 바꾸었다. 따라서 사람 눈에 양쪽이 보이거나 양쪽 후보가 모두 있어도 한쪽이 inferred일 수 있었다. 후보 탈락과 단순 점수 차이는 별도로 확인해야 한다.

## 변경

- 관측/이전2차항 차이를 전체 유지 범위의 휨 변화(abs(Δa)×span²/4)로 평가한다.2.5모델픽셀을 넘으면 즉시 관측에 반영하지 않는다.
- 새2차 모델이 전체 비교 범위에서4px 이내로 일관되며 최소3프레임·0.3초 지속되어야 확인한다. 실제 지지16행 이상 및 span40px 또는 전체범위65% 이상도 필요하다. 짧은 조각을 반복해서 보는 것만으로 긴 외삽 곡률을 승인하지 않는다.
- 의심 후보는 이전 모델과 관측 시각·신뢰도·간격 학습에 주입하지 않는다. 독립적으로 확인된 반대편 관측이 있다면 기존 신뢰 간격 보정은 계속 허용한다. 양쪽 모두 보류되면 이전 두 모델을 유지한다.
- 양쪽이 충분히 관측되면 점수 차이만으로 한쪽을 약한 관측으로 취급하지 않는다. 더 짧은 지지 또는 큰 이전 오차가 있는 경우에만 기존 약한 관측 보정을 사용한다.
- 원시 후보 탈락 사유·지지 행/범위·후보 품질·곡률 변화·확인 횟수/충분성/완료 여부를 텔레메트리에 추가했다.
