# 배포 코드 11분 지속 운행: PC 입력 / 카메라 (2026-10-27)

## 결론

- **PC 입력:** 11분 동안 지연이 누적되지 않았다.
  - 발행 9.78 FPS, 분당 최저 9.53 FPS.
  - 지연 p50/p95 229/498ms, 분당 p95 최대 537ms.

- **카메라 소스:** 10.00 FPS, 누락 0%, 지연 p50/p95 80/87ms.

  - PC 실행 중 CPU 센서 최대치(중앙값 84.4℃, 최고 89.5℃)는 카메라 실행(중앙값 63.6℃)보다 높았다.

## 해석과 한계

- PC 입력의 분당 FPS는 9.53~9.93이고, 10.0에는 못 미친다. 누락이 0.3~4.7%로 분마다 달랐다. 지연 p95가 시간에 따라 늘지 않았으므로 처리 큐 누적은 아니다.
  - 남은 누락은 PC 송신 시계와 카메라 tick의 위상 차(최신 1프레임 버퍼), 또는 처리 시간이 100ms를 순간적으로 넘는 프레임 때문으로 추정한다. 원인 분리는 하지 않았다.
- PC 지연(약 230ms)이 카메라(약 80ms)보다 큰 것은 장면이 달라서일 수 있다. PC 경로에는 JPEG 디코드·리사이즈, hub 대기, 도로 장면의 경계 추적이 더해진다. 카메라 장면이 다르므로 두 경로의 차이를 경로 자체의 비용으로 단정하지 않는다.
- 도로 장면의 카메라 경로 성능과 Depth 거리 정합은 차량 또는 도로가 보이는 환경에서 별도로 측정해야 한다.
- 원자료: `artifacts/long_run_20261027/{pc_11min,camera_11min}/`(frames.jsonl, stats.jsonl, run.json, summary.json). `smoke_pc/`는 도구 확인용 1.2분 실행이다.
