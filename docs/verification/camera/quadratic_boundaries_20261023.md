## 구현

각 좌우 경계는 `x(y)=C0+C1*y+C2*y²` 하나로 표시·저장한다. 직선은2차항0인
특수 경우다. S자/구간별 연결은 사용하지 않는다. 내부 계산은 u=(y-125)/50으로
정규화하고 텔레메트리는320×180 영상의 원래y 기준 계수를 반환한다.

- 검출 잔차를 계수 공간에서 보정. 짧은 부분은 상수, 넓은 부분 관측은1차,
  전체 관측은2차 보정한다. 양측 계수는 독립적이다.
- 관측 보정량은 전체 유효 구간의 최대 이동을 기준으로 단일 비율을 사용한다.
  행마다 clip하여 곡선이 조각나는 경로를 제거했다. 최대80px/s.
- 움직임 변환 후와 반대편 추론 후에도 단일2차식으로 재투영한다.
- 형상/교차 검증 후에만 이력 승인. 기존 유효 지지 구간을 유지하며 전체 높이로
  외삽하지 않는다. 부분 관측은 전체 모델의 미관측 행도 함께 움직일 수 있다.
- `left_image_coefficients`, `right_image_coefficients`, `image_curve_degree=2` 추가.
  기존 미터 단위 coefficient 필드는 비워 두어 영상 단위와 혼동하지 않는다.
- 중심선/고정2.1m/하단 고정/최초 무검출 가상 초기화 정책은 추가하지 않았다.
