# 하단 고정 시작점·실선 경계 검증 — 2026-10-22

## 변경 내용

0.21.0. 하단 시작점은 정규화 영상 좌표 (0.12,0.98)/(0.88,0.98),
BEV 시작점은 기본 좌 -1.2 / 우 +1.2로 고정한다. 근거리·원거리 기준점은
lane_boundaries.json에서 설정하며 관측 샘플링과 출력에 같은 투영을 사용한다.
기존 화면 전체 폭=BEV 12단위 투영이 가상 경계를 화면 중앙에 좁게 모으던 문제를 수정했다.

C0는 고정하고 C1과 C2를 함께 탐색한다. 오른쪽은 법선 오프셋을 별도 2차식으로
근사하며, 양쪽 시작점과 법선 폭 오차 허용값을 만족하는 쌍만 허용한다.
고정 시작점·2차식·완전히 동일한 법선 폭을 임의의 C1에서 동시에 정확히 보장할 수
없으므로 기존 폭 허용 오차 0.08 개발 단위 제약은 계속 적용한다.
기본 요청 폭은 차폭 1.8 + 여유 0.3 + 0.3 = 2.4이다.

RGB/AI 흰색선의 연속 거리 점수를 강화했다. 근거리 연결 지지가 없는 먼 주차선은
추종 점수에서 제외한다. 후보 폭을 늘리거나 관측 소실 시 경계를 지우지 않는다.
도로 전체 폭 지지 여부를 우선하고, 프레임 이동 제한과 장기 유지도 유지한다.
흰색선 거리장은 프레임당 한 번 계산한다.

상태와 무관하게 양쪽 경계를 실선으로 그린다. blocked/held 상태는 상단 문자와
telemetry로 전달하며 중심선과 조향 명령은 계속 없다.
멀티뷰의 고정 썸네일 크기 때문에 하단이 잘리던 문제도 실제 패널 크기 내 축소로 수정했다.
