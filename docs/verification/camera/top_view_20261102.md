## 후속: 일반 TOP 화면의 픽셀별 연속 점수색

일반 TOP 화면은 이제 이진 마스크 단색 대신 각 픽셀의 원시 차선 점수를 사용한다.
표시 임계값은 선택에만 적용하고 색은 고정 0~1 스케일의 연속 색상
(낮음 빨강→높음 보라)으로 정한다. 프레임별 최소·최대 정규화나 차선별 평균은 없다.
기존 RGB 배경과 80% 색상을 혼합하며 하단에 원시 점수 범례를 표시한다.
점수를 얻을 수 없으면 단색으로 대신하지 않고 RGB와 SCORE UNAVAILABLE을 표시한다.
실제 점수들이 비슷하면 색도 비슷하게 보이는 것이 정상이다.

변경은 TOP 일반 표시 대상이며 기존 YOLO 결과 일반 화면·명시적 단색 옵션,
인식 임계값·경계·경로 계산은 유지한다. 가상 경계와 주행경로의 선 색상은
종류를 구분하는 기존 표현이며 픽셀 점수에 해당하지 않는다.

전체194개 검사 통과. 특히 동일 임계값0.5를 넘는0.60/0.65의 색상 차이,
임계값 미만 RGB 유지, 점수 부재 시 단색 미표시를 확인했다.
실제 장치 카메라·도로 기본/전체/구간색 4화면 수신 확인, 텔레메트리329프레임.
종료 카메라/basic/일반0.50 복원. 이미지와 결과는 artifacts/top_confidence_20261102.
배포 전 백업은 artifacts/top_confidence_20261102/device_before이며 롤백:

```powershell
python src/hl_camera_bringup/scripts/manage_virtual_guidance.py rollback --device-ip 192.168.201.2 --backup artifacts/top_confidence_20261102/device_before
```

아래는 최초 TOP 뷰 구현 기록이며 일반 화면의 단색 설명은 위 변경으로 대체된다.

기존 BEV 스트림(rtsp://192.168.201.2:8553/bev)의 기본 모드 정지 안내 화면을

바탕에 기존 경계·가상 경계·주행경로·정지선을 같은 좌표계로 표시한다.

## 범위와 제한

- 모델, 인식 임계값 0.50, 경계 추적·주행경로 계산은 유지한다. 표시 전용 변환이다.
- TOP 표시 전용 원본 사다리꼴 좌표: 하단 (0.02,0.98)/(0.98,0.98),
  상단 (0.30,0.55)/(0.70,0.55). 기존 통로 투영의 좁은 중앙 영역을 사용하는 대신
  도로 양옆을 포함한다. 원본 영상 크기에 대한 정규화 좌표이며 사용자 보정 UI는 없다.
- 동일한 역방향 좌표표로 RGB와 원시 차선 점수를 최근접 샘플링한다.
  유효 영상 밖은 검정. 좌표표는 입력 크기·투영 행렬 변경 시에만 다시 만든다.
- 일반 표시는 RGB+기존 차선 마스크, 원본 RGB 옵션은 RGB만 표시한다.
  점수 구간색/연속 점수/임계값 마스크 옵션은 기존 표시 임계값을 사용한다.
  3분할 옵션의 TOP 화면은 단일 RGB+구간색이며, YOLO 결과 화면의 3분할은 유지한다.
- 전체 모드의 경계·경로·정지선은 기존 설정대로 별도 오버레이된다.
  경계 표시 off는 추적 경계선만 숨기며 원시 차선 마스크와 경로는 별개다.
- 카메라 높이·자세·렌즈를 보정한 결과가 아니다. 거리·폭은 실측값이 아니고,
  비평면 도로와 차량·나무 같은 입체 물체는 왜곡된다. 색칠된 모델 출력은
  실제 차선임을 보증하지 않는다. 인식 검토 시 원본과 함께 비교한다.
