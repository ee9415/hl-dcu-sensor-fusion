# 한라대 가상 좌우 경계선 검증

작성일: 2026-10-21

## 요구사항과 변경 근거

대상은 한라대학교 캠퍼스 도로다. 도색 차선이 모호하거나 도로가 갑자기 넓어져도
차량이 통과할 통로의 좌우 경계가 함께 벌어지지 않게 한다. 중심선 추정 후 폭을
더하는 방법을 사용하지 않고, 좌우 경계 변수를 직접 공동 피팅한다.

- 각 경계는 독립적인 예측 위치 주변의 차선 마스크를 우선 관측한다.
- 주행 가능 영역의 가까운 외곽은 낮은 가중치로 참고하고 먼 외곽은 무시한다.
- 좌우 2차 다항식에 `right(s)-left(s)=차폭+좌여유+우여유` 등식 제약을 적용한다.
- 이전 경계 또는 초기 차량 좌우 위치로 정규화하고, 두 경계에 공통 비율의
  프레임 변화 제한을 적용해 간격과 곡선 연속성을 유지한다.
- 가까운 가시 도로의 폭 부족/경계 충돌은 무효, 먼 좁아짐은 표시 범위 축소.
  완전한 근거리 도로 입력 소실만 최대 0.5초 유지한다.
- 경계 근거 부족 시 inferred, 입력 소실 유지 시 held이며 점선으로 표시한다.
  넓은 무표시 도로에서의 추정은 실제 차로 또는 진행 경로를 확인했다는 의미가 아니다.

## 변경 파일과 호환성

- `apps/yolopv2_standalone/lane_boundaries.py`, `lane_boundaries.json`: 새 추정기와 설정.
- `yolopv2_node.py`: 활성 중심선/목표점/선회 경로를 경계 전용 처리로 교체.
- `tools/oak_recorder.py`: BEV 제목, 경계 범례, 선회 버튼 숨김.
- `tools/frame_csv_logger.py`: 경계 상태·설정·좌표 배열의 추가 열 저장.
- 기존 중심선 알고리즘과 테스트 파일은 수정/삭제하지 않았다.
- RGB/객체/Depth, 영상 녹화, 포트/기존 전송 식별자와 CSV 기존 열은 유지했다.
  중심선 유효성은 false, 계수는 빈 값, 선회 모드는 disabled로 송신한다.
- 소스 앱 버전 0.14.1 → 0.15.0. 장비 설치 버전은 변경하지 않았다.

## 설정과 미확정 사항

`lane_boundaries.json` 초기 차폭 1.8 m, 좌우 여유 각 0.3 m, 총 2.4 m는
실측 제원이 없는 상태의 임시 개발값이다. 앱 시작 시 읽으며 수정 후 개발 앱
재시작 또는 패키지 재빌드/재배포가 필요하다. 음수/비수치/NaN/범위 초과는 거부한다.

개발 IPM은 기존 고정 사다리꼴과 동일하며 미보정 상태다. 실제 m 정확도와
차량 기준 장착 위치/높이/pitch는 검증 필요. 현재 폭은 동일 전방 좌표의 횡방향
간격이며 급곡선의 법선 방향 여유 폭이나 차량 회전 포락선 보장이 아니다.
차량 운동 보상, 교차로 출구 선택, 연석 전용 검출, 객체 회피 및 차량 제어는
이번 구현 범위에 포함하지 않는다. 도로/차선 마스크 오검출에 대한 현장 평가가 필요하다.

## 검증 방법과 결과

Windows 번들 Python 3.11 / NumPy 2.3.5에서 다음 실행:

```powershell
$env:PYTHONPATH = 'apps/yolopv2_standalone'
& '<bundled-python>' -m unittest discover -s apps/yolopv2_standalone/tests -v
```

| 항목 | 결과 |
| --- | --- |
| 전체 회귀 테스트 | 68개 통과 |
| 경계선 테스트 8개 | 비대칭 여유 폭, 설정 검증, 일측/양측 급확장, 곡선과 일측 차선 소실, 폭 부족/원거리 축소, 소실 만료/역순 입력, 도로 분리, 가시 충돌, 투영/렌더링/JSON 확인 |
| 호스트 통합 테스트 1개 | DepthAI 대체 객체로 실제 후처리 메서드 실행, 결과/BEV 크기·시각·번호와 경계 전송 확인 |
| TCP CSV 테스트 | 기존 누락/시계 검사와 경계 상태·폭·좌표 배열·무효 배열 저장 확인 |
| 정적 구문/공백 검사 | Python compile 및 git diff --check 통과 |
| 합성 BEV 이미지 | 노랑/하늘색 두 경계만 존재하는 렌더링 육안 확인 |

첫 샌드박스 테스트는 Windows 루프백 접속 WinError 10013으로 TCP 항목만 실패했다.
루프백 접근을 허용한 재실행에서 전체 통과했다. WSL 접근은 E_ACCESSDENIED로
불가능하여 Windows 번들 런타임을 사용했다. Serena는 다른 프로젝트를 가리켜
이 저장소 접근을 거부해 일반 파일 도구로 읽고 수정했다.

데스크톱에서 전체 마스크 추정+두 화면 경계 렌더링 25회 표본(최초 3회 제외)은
p50 21.44 ms, p95 23.28 ms. 장비 FPS나 RVC4 성능 측정값은 아니다.

카메라 실행/배포, 실제 RTSP/GUI, 녹화 버튼 동작, 한라대 현장 도로 정답 비교는
미수행이다. ROS2 경로가 아니므로 colcon/topic/TF 검증은 해당하지 않는다.
