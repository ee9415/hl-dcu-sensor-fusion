# 한쪽 흰색선 기준 고정 폭 경계 — 2026-10-22

## 구현

0.22.0. 양쪽 고정 근거리 앵커에서 각각 흰색선 연결 관측을 찾는다.
최소12개 관측행, 전방4개발단위 이상 길이를 요구하고 제한된 관측 공백을 허용한다.
관측이 LEFT/RIGHT 한쪽뿐이면 해당 선과의 오차를 경계쌍 선택의 우선 기준으로 삼는다.
반대편은 기존 법선 오프셋의 2차식 근사로 생성해 설정 폭2.1 및 허용오차0.08을 유지한다.
양쪽 관측은 함께 사용하고, 둘 다 없으면 도로 마스크 변화에도 이전 곡선을 유지한다.
도로 지지는 공간 충족 상태와 약한 동점 기준으로 남긴다.

하단 시작점 C0 -1.05/+1.05 및 기존 투영, 좌우 실선, 중심선 제외 유지.
재등장/기준쪽 변경에도 1.0개발단위/초 이동 제한과 최대dt0.2초를 적용한다.
35개 기본 후보/국소 탐색/주기 전체 탐색/배치 렌더링은 유지한다.
telemetry boundary_reference_side와 RGB/BEV 상단 REF LEFT/RIGHT/BOTH/NONE으로
현재 기준 관측을 표시한다. REF는 검출기의 판정이며 흰색선 정답 라벨은 아니다.
