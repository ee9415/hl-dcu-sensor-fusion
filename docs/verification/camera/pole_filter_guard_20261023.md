# 가로등 필터 보완 및 장치 검증

날짜: 2026-10-23. 기반4381513, 배포0.30.3, 카메라192.168.201.2.

## 변경 근거

기존 가로등 필터는 연속 밝은 줄기가 도로 마스크 밖에4행 이상 존재하면
그 아래 정상 차선까지 모두 제거했다. y110~175에 수직 흰색선2개,
도로 마스크 y130부터인 재현에서 양쪽UNAVAILABLE, 필터 해제 시OBSERVED였다.

클로드의 밝기 적응/점선 연결/부분 기울기 보정은 유지했다. 가로등 제거는
도로 허용 마스크에 진입한 뒤12행 이내 전이부에만 적용하도록 제한했다.
도로 내부로 오래 이어지는 실제 차선까지 기둥으로 취급하지 않는다.
이는 범위를 제한한 휴리스틱이며 기둥과 차선을 완벽히 분류하지는 않는다.

## 검증

- 전체60개 테스트 통과. 새 수직차선 회귀는3프레임 모두양쪽OBSERVED/쌍유효,
  선 위치 오차3px 미만을 요구한다.
- 기존 실제 장면 가로등 제거, 두 점선 기울기 복귀, 밝은 노면 시험도 함께 통과.
- 실행 환경변수0.30.3 확인.
- 장치30초/302프레임9.9946379 FPS, 소스누락0, 무효경계쌍0, 중심선0.
- 좌286 OBSERVED/15 HELD/1 PARTIAL, 우302 PARTIAL. 전역참조BOTH287/RIGHT15.
- 별도5초 RGB26장/결과25장/텔레메트리51개, 첫8장 비교 시트 확인.
  현재 정지 장면에서 좌우 경계가 유지됨. 원거리/곡선 이동 정확도는 미확정.
- 자료: `artifacts/fix_0303_fps/`, `artifacts/fix_0303_video/`.
  영상 대응은 수신시각 기준이며 정답 좌표 비교에 의한 전 구간 정확도 측정은 아님.

## 사용자 제안 가상 경계 전략에 대한 설계 의견 (이번에는 미구현)

- 양쪽 관측: 실제 선 우선, 직선 또는 적절한 곡선 모델 적용.
- 한쪽 관측: 관측한 굽음과 최근 폭 프로파일로 반대편 추론. 폭이 없으면
  설정한 원근 폭을 저신뢰 초기값으로 사용. 일정 픽셀 간격 복사는 피함.
- 양쪽 소실: 유효 이전 이력+영상 움직임 우선. 최초 이력도 없을 때에만
  설정 시작점/원근 폭으로 가상 초기화. 관측과 추론 상태를 분리.
- 재관측: 설정 시작점에 묶이지 않게 실제 관측으로 점진 복귀.
- 2차 곡선은 완만한 커브에 적합하나 전체 구간 외삽이나 S자 구간을 단일2차식으로
  강제하지 않음. 직선/제한된 구간 곡선 선택 및 연결부 검증 필요.

이번 작업은 승인된 필터 보완과 장치 검증만 수행했으며, 최초 무검출 상태에
새 기본 가상선을 그리는 정책은 아직 추가하지 않았다.
