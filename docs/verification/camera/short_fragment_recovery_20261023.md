# 짧은 흰색 선분 복귀 검증

날짜: 2026-10-23. 카메라192.168.201.2, 최종0.30.2.

## 변경

기존 긴 선 검출은 우선 실행하며 성공 시 결과를 그대로 사용한다. 실패한 경우에만
174행 시작점,2점부터의 방향 추정,최대14행 공백 및 방향차0.7 이내의 제한 연결을
수행한다. 후보 최대28개. 기존 밝기/도로/객체 제외 기준은 그대로다.

가까운 연속 선분5점 이상/8px 이상,선형잔차1.5px 이하인 부분 관측을 기존 이력
보정에 사용한다. 최초 선 전체를 이 짧은 조각으로 생성하지 않는다. 관측 없는
공백이나 먼 행을 현재 관측으로 표시하지 않는다. 근거리 선분만 위치 보정의 근거다.

부분 관측은 전체 기존 형상을 같은 양만큼 이동시키되8px/0.1초 이내로 제한한다.
짧은 근거만으로 곡률을 바꾸지 않는다. 기존 쌍/형상 검증도 적용한다. PARTIAL 신뢰도는
0.65 미만이며 폭 학습/반대편 복원 기준이 되지 않는다. 전체 선 정확도를 의미하지 않는다.

처음에는 기존 검출에도 새 시작점/추적을 적용했으나 기존 좌측 형상이 바뀌어 제외했다.
부분 행만 이동하는 중간 구현에서도 오래된 구간과 굴곡이 생겨, 최종은 형태 보존 이동으로
변경했다. 최종 검증 경로만 아래에 기록한다.
