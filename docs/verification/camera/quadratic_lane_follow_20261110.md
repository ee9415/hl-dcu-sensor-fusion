# 부분 관측 재발 보완·최종 2차 차선 모델 (2026-11-10)

## 사용자 요구

한쪽이 잘 보이고 반대쪽이 약하거나 보이지 않으면, 잘 보이는 쪽의 현재 형상에 마지막 신뢰 간격을 더하거나 빼서 반대쪽을 표시한다. 사용자는 후속 확인에서 최종 분홍 표시선도 항상 2차 다항식으로 고정하도록 명시했다. 기존 스켈레톤 세부 형상을 그대로 보존하는 표시 요구는 이 선택으로 대체된다.

## 재발 원인

- code4는 전체 미검출일 때만 보정했다. 짧은 일부 관측으로 상태가 observed가 되면 미관측 구간에도 옛 휨이 남았다.
- 새 관측점만 이동하고 내부 빈 행/표시 범위 밖 좌표를 옛 위치에 남기면, 관측 후보와 이전 곡선은 각각 정상이어도 합친 표시 배열에 꺾임이 생겼다. 실제58.0/58.2초 자료에서 후보/이전선은 형상 검사를 통과하지만 혼합 배열의 기울기 변화는 약3.70으로1.8 기준을 넘었다. 쌍 충돌 처리가 좋은 오른쪽 관측까지 held로 되돌렸다.
- 횡단보도 진입 시55.1초 오른쪽 마스크는53행 길이로 실제 검출됐지만 끝이120행으로, 하단 기준 약122.4행에 미달해 후보에서 제외됐다.
- UI 전송 위치와 RTSP 출력 프레임은 비동기다. 재생 막대 숫자만으로 인식/TOP 프레임 시각을 확정할 수 없다. 출력 영상 자체에 시각을 표시하고 확인해야 한다.

## 최종 구현

- 실제 차선 후보는 기존 마스크 기반 검출·지지·재검출 확인을 사용한다. 관측 모델은 x(y)=ay²+by+c이다. 이전/현재 모델의 계수를 점진적으로 혼합하므로 측정 행, 빈 행, 새로 드러난 행이 동일한2차식에 놓인다.
- 일부 관측이더라도 형상 품질·지지 행 수·최근 관측과의 차이에서 반대편보다 약하면, 약한 후보를 매번 모델에 다시 주입하지 않는다. 더 신뢰할 수 있는 반대편의 현재2차 곡선±1차 원근 간격을 목표로 삼는다.
- 간격은 실제 양쪽 관측에서만 학습한다. 약한 추정값으로 간격·관측 시각·신뢰도를 스스로 갱신하지 않는다. 직접 부분 관측 장면에서 시작한 경우에도 충분한 공통 실제 지지가 있으면 간격을 초기 확보할 수 있다.
- 원근 간격은1차식이므로 반대편2차 곡선에 더해도 결과는2차식이다. 좌우 표시 범위가 달라도 같은 계수 모델을 기존 표시 범위에 평가해, 끝부분에 옛 곡률을 섞어 남기지 않는다. 양의 간격 조건 밖은 임의의 선으로 연결하지 않는다.
- 기존 관측/미관측 이동 상한·속도 배율·쌍 유효성 검사와 최초 미관측 반대편 생성 금지는 유지한다.
- 기존 추적 이력이 있고 실제 지지가 충분히 긴 원거리 후보는 하단 기준 하나만으로 버리지 않는다. 실제 관측점 마스크는 별도로 유지해 실선/점선을 구분한다.
- 인식/TOP에 처리된 원본 시각과 LEFT/RIGHT 상태를 표시했다. TOP은 RGB와 같은 곡선을 기존 미보정 투영으로 옮기며 독립 곡선을 만들지 않는다.
