# 컨투어 경계 시간축 추적 통합

날짜: 2026-11-04. 소스 패키지 버전: 0.33.3. 장치 배포는 수행하지 않았다.

## 결정과 변경 근거

사용자 요청에 따라 설계 토의를 마무리하고 경계별 추적과 학습 폭 보조를 구현했다.
공유 곡률·소실점을 강제하는 새로운 칼만 모델은 도입하지 않는다.
기존 화면은 관측 왼쪽이 사라지면 반대쪽 경계와 화면 비율 폭으로 새 가상선을
생성했다. 실제 관측선과 가상선의 근거가 달라 전환 시 급변할 수 있었다.

전체 처리(full) 모드는 `ImageBoundaryTracker.update_contours` 한 번의 결과를
안내·정지선·텔레메트리 및 RGB/TOP 표시가 공유한다. 기존 RGB 흰색선 검출 API는
호환용으로 유지하지만 full 처리에서 동시에 실행하지 않는다. 따라서 full의
관측 근거는 현재 NN 마스크 컨투어이며, 마스크 없이 RGB 흰색선만으로 관측을
초기화하던 동작은 종료했다. 최초부터 보이지 않는 반대쪽을 고정 폭으로 만들지 않는다.

- 컨투어 후보 전체를 이전 경계와 먼저 연결한다. 원래 짝 판정에서 버려지던
  후보도 검토하고 같은 그룹을 양쪽 경계에 중복 사용하지 않는다.
- 영상 좌표 320×180, 48개 고정 행에서 추적한다. 결과는 단일 2차식이다.
- 실제 관측 보정은 전체 기존 지지 구간에서 최대 80px/s, 반대쪽·학습 폭에 의한
  미관측 보정은 최대 20px/s로 단일 비율 제한한다. 물리적 m/s가 아니다.
- 기본 시간상수 0.25초, 큰 일관 오차 추종 0.12초, 폭 보조 0.4초.
  이 값들은 초기 튜닝값이며 도로별 최적값을 주장하지 않는다.
- 큰 후보 오차는 바로 반영하지 않는다. 최대 연결 거리 60px 이내의 후보에 대해
  최소 0.2초·3회 일관성 확인 후에도 이동 상한을 적용한다.
- 폭은 실제 양쪽 관측이 정렬된 공통 행에서만 학습한다. 최소 3회 근거가 있는
  폭을 사용하고, 마지막 양쪽 학습 후 3초를 넘으면 폭 보조를 중단한다.
- 한쪽 미검출은 최대 1.5초, 양쪽 관측이 없을 때는 각 경계의 마지막 실제 관측 후
  0.6초까지 유지한다. 가상 결과는 관측 시각·신뢰도·폭 학습을 갱신하지 않는다.
- 시간 역행·동일 시각·1초 초과 단절·해상도 변경·큰 장면 밝기 변화 시 초기화한다.
  노드에서는 source/processing/media epoch 전환도 초기화한다. 정상적인 프레임
  번호 건너뜀만으로는 초기화하지 않는다.
- 경계 숨김·컨투어 숨김·raw RGB 표시는 추적 입력을 끊지 않는다.
- 실제 관측 구간은 자홍색, 유지·추정·기존 먼 구간 연장은 노란 점선이다.
  표시용 변환은 새로운 경계나 추적 상태를 만들지 않는다.

기본 처리(basic)는 기존처럼 시간축 추적·안내를 우회하고 프레임별 표시를 유지한다.
이번 연속성 기능은 full 모드에서 사용한다. 텔레메트리 모델은
`mask_contour_temporal`, 단위는 기존 `image_pixels_320x180`이며 실제 거리 필드는 비운다.

## 검증 방법과 결과

새 연속 프레임 테스트는 다음을 검사한다.

- 한쪽 소실의 연속성, 반대쪽 이동에 따른 점진 보정, 양쪽 소실·장기 소실 종료
- 한 프레임 오검출, 반복 재검출 보정 상한, 후보 순서와 인접 방해 후보
- 화면 가장자리의 넓은 초기 차로, 오른쪽 후보 2개가 왼쪽을 사칭하는 경우
- 경계가 영상 중심을 통과할 때 기존 연결 유지
- 가상값의 폭 학습·실제 관측 시각 갱신 금지
- 표시선 다항식과 텔레메트리 좌표 일치, 10/20/30FPS 비교
- 시간·해상도·장면 전환 초기화 및 실제 노드의 표시 전환·source epoch 전환

저장된 실제 마스크 `artifacts/lane_contours_20261103/partial_extension/current_130_0.npz`에
왼쪽 절반 제거와 오른쪽 0~8px 이동을 주입해 20FPS·30프레임으로 재현했다.
실제 주행 연속 영상이 아니라 실제 마스크를 이용한 통제된 실패 주입이다.

| 지표 | 기존 프레임별 표시 | 새 추적 표시 |
|---|---:|---:|
| 왼쪽 미검출 전환 순간 최대 이동 | 78.7861px | 수치 오차 수준의 0px |
| 30프레임 구간 왼쪽 최대 이동/프레임 | 78.7861px | 0.4594px 미만 |

실제 양쪽 관측 초기화 성공, 소실 왼쪽의 held/inferred 상태 유지, 오른쪽 관측 유지,
미관측 이동의 20px/s 상한을 검증 스크립트가 확인하며 위반 시 실패한다.
결과 JSON과 비교 이미지는 `artifacts/contour_temporal_20261104/`에 로컬 보관한다.

재현 명령:

```powershell
$env:PYTHONPATH='apps/yolopv2_standalone;tools'
& .\.venv\Scripts\python.exe -m unittest apps/yolopv2_standalone/tests/test_contour_temporal.py apps/yolopv2_standalone/tests/test_boundary_pipeline.py
& .\.venv\Scripts\python.exe src/hl_camera_bringup/scripts/verify_contour_temporal.py artifacts/lane_contours_20261103/partial_extension/current_130_0.npz artifacts/contour_temporal_20261104
```

전체 회귀는 기존 WSL Ubuntu-22.04 환경에서 실행한다. 이전 Windows 실행의 소켓·임시
파일·스레드 종료 오류와 구분한다. 최종 실행 결과는 아래 변경 이력에 기록한다.

- 최종 전체 회귀: 348개 통과, 55.239초. 로그: `artifacts/contour_temporal_20261104/full_tests_final.log`.
- Windows 대상 연속 프레임 테스트 13개 및 실제 저장 마스크 실패 주입 검사 통과.
- `git diff --check` 통과. 장치 빌드·배포·실주행 검사는 수행하지 않았다.

## 한계와 적용

첨부된 11분 10초 장면 자체의 연속 원본 마스크는 이번 재현에 사용하지 않았다.
정답 라벨 대비 정확도, 실제 커브·피치 변화·분기·차선 변경의 완전한 경계 ID 관리,
실장치 처리 FPS와 제어 안정성은 추가 현장 검증이 필요하다. 밝기 기반 장면 전환은
급격한 노출 변화에도 초기화될 수 있다. 광류/IMU 예측은 이번 경로에 적용하지 않았다.

소스 구현·오프라인 검증이며, 실행 중인 카메라 앱을 변경하거나 녹화를 중단하지 않았다.
실제 영상에 적용하려면 0.33.3 패키지를 빌드·재설치해야 한다.
