# 관측 구간 융합 및 교차 이력 차단 검증

- 날짜: 2026-10-23
- 배포: 192.168.201.2, app 0.30.0
- 기준: 원본 0.25.0. 실패한 구간 ROI 전략은 재도입하지 않음.

## 근거와 변경

이전 변수 추적에서 부분 흰색선 검출 결과가 `_complete`의 전체 높이 2차
외삽으로 교차하고, 최초 잘못된 쌍이 이력에 저장되어 반복 복원되는 것을 확인했다.
원인 자료는 `boundary_variable_debug_20261023.md`에 기록했다.

1. 검출/밝기/객체 제외 및 기존 움직임 추정은 유지.
2. 전체 높이 다항식 재외삽 제거. 관측된 행만 현재 검출과 융합하고 나머지는 예측 유지.
3. 동일 행에서 최대 80px/s 보정. 10 FPS에서 8px이며 카메라 움직임 자체의 상한은 아님.
4. 최종 쌍 검증 후에만 이력 저장. 실패하면 한쪽씩 유효한 반대편과 검사하고,
   모두 실패하면 별도로 보관한 유효 쌍 복원.
5. 복원된 쪽은 HELD, 신뢰도 최대 0.15, 관측 참조 해제. 양쪽 동시 관측 행만 폭 학습.
6. 현재 관측은 밝은 실선, 유지/추론 구간은 어두운 실선. 중심선 없음.

하단 고정·2.1m 고정은 없음. 최초 무검출이나 명확한 장면 전환/시간 초기화 때에는
유효 이력이 없을 수 있으며, 이때 임의의 선을 정상 검출로 표시하지 않는다.

## 검증 결과

| 검증 | 결과 |
|---|---|
| 전체 단위/통합 테스트 | 47개 통과 |
| 기존 실제 시작 입력 재생 | 40프레임, 최초 검출 이후 무효 쌍 0 |
| 재생 표시-검출 잔차 | 최대 1.731px (320×180 내부 좌표) |
| 합성 30초 관측 소실 | 유효 쌍 유지, 동일 좌표 변동 0px |
| 합성 12px 이동 재등장 | 최대 한 단계 6.871px, 최종 양쪽 OBSERVED |
| 배포 후 30초 | 300프레임, 10.0021 FPS, 소스 누락 0 |
| 카메라 경계/중심선 | 무효 쌍 0, 중심선 0, 양쪽 OBSERVED 300 |
| 카메라 동일 행 변위 | 최대 3.188px/프레임 |
| 카메라 표시-검출 잔차 | 최대 1.837px |
| 별도 5초 영상 수집 | RGB 26장, 결과 24장, 텔레메트리 50개 |

표시-검출 잔차는 내부 후보와 출력의 차이이며 실제 흰색선 정답 대비 정확도가 아니다.
멀티뷰와 수집 결과 24장을 확인했다. 정지 장면에서 나무/하늘까지 연장된 X 교차는
사라졌고 흰색 차선 근방을 따라 표시됐다. 먼 끝부분/차선 가장자리의 작은 오차는
남아 있으며, 수동 정답 주석 기반 정확도를 산출한 것은 아니다.

첫 수집은 RGB RTSP 503으로 실패했고 재시도는 오류 없이 완료했다. 수신 영상은
약 5 FPS이므로 모든 처리 프레임을 영상으로 검증한 것은 아니다. RGB/결과는 수신
시각 기준 근접 대응이며 장치 시각으로 정확히 동기화되지 않았다.

현재 카메라가 촬영하는 화면은 정지 장면이다. 움직이는 커브, 실제 가림과 재등장은
카메라에서 검증하지 못했다. 합성 소실/복귀 결과를 실제 주행 검증으로 해석하면 안 된다.
BEV는 미보정 참고 투영이며 Depth는 화면 촬영 조건에서 유효한 도로 거리 검증에 사용하지 않았다.
ROS2 구성 변경은 없으며 이 standalone 앱 검증에서 colcon/TF 검증은 수행하지 않았다.
