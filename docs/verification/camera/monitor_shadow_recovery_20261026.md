# 모니터 환경 변경 후 그늘 차선 복원 (2026-10-26)

## 원인과 근거

반복 재생 중인 장치 입력 100프레임을 `artifacts/monitor_change_20261026_before`에 수집했다. 첫 프레임 320×180 좌표 (294~297,140)의 오른쪽 흰색선 밝기는 103.7~110.0이고 YOLOPv2 차선 지지가 있다. 도로/차량 마스크는 이 좌표를 허용하지만, 도로 전체 중앙 밝기에서 계산한 임계값 175.53 때문에 삭제된다. 모니터 변경 자체의 인과관계는 이전 모니터 동일 입력 비교가 없어 확정하지 않는다. 현재 입력의 밝기 조건과 후처리 탈락은 확인했다.

일부 차량 박스 내부 조각도 제외되지만, 밝기 조건만 보완해도 오른쪽 관측이 회복된다. 차량 마스크를 일괄 완화하지 않는다. 기존 audit의 raw evidence 비교는 밝기 및 가로등 필터를 함께 제거하므로 밝기 단독 실험으로 해석하지 않는다.

## 수정 및 영향 범위

- 기존 지역 대비·중성색 흰색선 증거를 통과하고, 좌우 3픽셀 이내 NN 차선 지지가 있으며 밝기 85 이상인 부분에 한해 전체 밝기 임계값을 우회한다.
- 가로등·도로·차량 제외 마스크, 곡선 연결·폭·교차 검사, 후보 수, 중심선 제외는 유지한다.
- NN만 있고 실제 밝기 대비가 없는 부분은 복원하지 않는다. NN 오검출과 실제 밝은 능선이 겹치는 경우의 위험은 남는다.
- 진단 수집 시 변경 가능한 diagnostics 딕셔너리를 복사해 각 프레임 값을 보존한다. 기존 자료에서는 이미 스냅샷된 telemetry diagnostics를 사용한다.
