# 영상 좌표 경계·움직임 보정 검증 (2026-10-22)

## 변경 근거와 구현

손으로 촬영한 영상에서 고정된 BEV 투영·하단 시작점·폭 제약이 실제 흰색선과 충돌함.
실시간 노드는 ImageBoundaryTracker를 사용하며 구형 BoundaryTracker는 회귀 비교용으로 남김.
RGB 320x180에서 좌우 흰색 연결 후보를 각각 검출, 강건 2차식으로 적합한다.
노면 주변 제한, 노면 중앙 밝기보다 25 이상 밝은 후보(최소125), 차량 박스 억제를 적용.
차량 박스 하단 10%는 주차 차량 옆 차선까지 지우지 않도록 검사 가능하게 둔다.
최소14개 관측행·32픽셀 세로 길이를 요구. 주행 방향·폭·시작점은 강제하지 않는다.

160x90 회색 영상에서 최대42개 노면 패치의 이동을 구하고 강건 affine 변환을 적합한다.
이 변환으로 이전 경계를 현재 영상으로 이동한다. 변환이 불확실하면 제자리에 유지하면서
신뢰도를 더 빨리 낮춘다. 재검출 시 보정량을 제한하고 전체 곡선을 다시 적합해 연결부를 평활화.
실제 관측과 최종 표시가 크게 다르면 ALIGNING 표시, 신뢰도 감소.
이전에 양쪽을 관측한 영상 폭 프로파일만 반대편 추정에 사용할 수 있다.
최초 관측 이력이 없으면 임의의 가상 선은 만들지 않는다.

BEV는 참고 투영 화면으로만 사용. 영상 경계 검출·선택에는 BEV 변환을 사용하지 않는다.
폭 및 거리 관련 telemetry는 null, 영상 좌표·motion confidence/matrix는 별도 필드로 내보낸다.
정지선은 같은 영상 경계 사이에서 검사하며 중심선은 생성/표시하지 않는다.
