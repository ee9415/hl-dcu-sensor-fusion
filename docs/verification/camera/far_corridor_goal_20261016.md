# 앞쪽 통로 목표 기반 중심선

작성일: 2026-10-16. oakapp 0.12.0.

## 근거

사용자 영상에서 중심선이 원거리 도로 대신 오른쪽으로 향하는 문제가 제기됐다.
기존 estimate_centerline은 영상 높이 50~98%만 추적하고 같은 범위를 개발 BEV로
변환했다. 따라서 상단 50% 밖의 도로는 계산에서 제외될 수 있었다.
단순히 필터를 부드럽게 만드는 것만으로는 제외된 원거리 통로를 따라갈 수 없다.

## 변경

- 카메라 노드의 ROI를 높이 38~98%로 확장. 함수 기본값은 기존 50%로 유지해
  기존 호출의 동작은 보존한다. 테스트와 노드는 새 인자를 명시한다.
- 호모그래피도 새 ROI에 맞춘다. 0..40/±6 좌표는 여전히 미보정 개발 단위이며
  실제 미터로 간주하지 않는다. 이전 BEV 수치와 물리적 거리 비교를 해서는 안 된다.
- 아래에서 위로 연결된 통로 추적/6행 초과 단절 시 중단은 유지한다.
- 추적된 원거리 1/4 구간에서 연속 8행 밴드를 비교한다. 폭 중앙값과 변동이 작은
  밴드의 중앙을 목표로 사용하여 단일 픽셀과 넓은 원거리 급확장의 영향을 줄인다.
- 1/2차 후보의 근거리 위치를 유지하면서 원거리 목표 오차를 우선 최소화한다.
  2차 계수 121개 후보를 탐색하며 기존 곡률·기울기 상한 안에서 1차항을 결정한다.
  통로 이탈·기존 경로 차이·불필요 곡률에도 비용을 둔다. 3차항은 0이다.
- 유효하지 않은 저차 근사라도 원시 관측이 유효하면 목표 기반 후보를 다시 만든다.
  이후 시간 필터와 최종 보수적 제한기의 경계 검사는 계속 적용한다.
- 마지막 출력의 매 프레임 위치/방향각/곡률 제한은 변경하지 않는다.
- 영상의 흰색 십자는 현재 목표점이다. 마스크 오류까지 교정한 안전한 경로 표시는 아니다.
- HEALTH에 목표 개발좌표/영상좌표, 최종 경로 목표 오차, 원거리 밴드 내부 도달 수,
  기존 ROI 위쪽 목표 프레임 수, 영상 픽셀 오차 평균/최대를 추가했다.
  집계는 유효 중심선과 목표가 있는 프레임만 포함한다. 무효 프레임은 별도 기존 집계로 확인한다.

## 검증

Ubuntu unittest 54개 통과. 새 테스트는 기존 ROI 위쪽 목표 사용, 가까운 한쪽 확장에도
목표 유지, 단절된 상단 영역 미사용, 원거리 넓은 패치 대신 좁은 통로 선택,
갑작스러운 목표 이동에도 프레임 변화 제한 유지, 무효 입력을 포함한다.
기존 일반 도로 및 교차로 미리보기 테스트도 통과했다.

실영상은 모니터에서 재생하는 도로 영상을 OAK가 촬영한 환경이다.
사용자가 표시한 빨간 선 자체를 정답 데이터로 추출하거나 동일 프레임을 재현한 시험은 아니다.

## 남은 한계

목표 추출은 신경망 주행 가능 마스크에 의존한다. 실제 차로 중앙/장애물 회피 정답은
아니며 대상 구간의 차량 주행 안전성을 검증하지 않았다. 특히 영상 장면 전환이나
급변에서는 기존 변화 제한 때문에 목표 추종 지연/경계 충돌에 따른 무효가 남는다.
원거리 밴드에 포함됐다는 통계만으로 정확한 차로 추종이라고 판정하면 안 된다.
현재 선과 목표가 어긋날 수 있음을 십자 표시와 로그 오차로 확인할 수 있다.
