# 중앙 추종선 표시

## 끝점 기준 변경 (2026-11-17)

사용자 요청으로 중앙 경로의 목표를 별도 추정 복도에서 **탑뷰에 실제 표시되는 좌우 분홍 차선의 중점**으로 변경했다. 시작점은 기존 원본 이미지 기준(159.5,178.105;320×180)을 유지한다. 탑뷰의 헤더 아래72행부터 앞쪽 공통 가시 행을 찾아 각 차선과의 교점을 계산하고, 같은 TOP 높이의 두 x좌표 평균을 끝점으로 사용한다. 추정/유지 차선도 화면에 표시된 곡선 그대로 사용한다. 두 선이 함께 보이는 유효 높이가 없으면 임의 끝점을 만들지 않는다.

탑뷰에서 t=(시작y-y)/(시작y-끝y), x=시작x+(끝x-시작x)×t²인 단일2차 곡선을 만든다. 시작점의 횡방향 접선은0이며 두 끝점을 정확히 통과한다. 별도 끝점 평활화로 표시 차선 중점에서 뒤처지게 하지 않는다. 차선 자체의 기존 추적 평활화는 유지한다. 원본 시점 영상에는 같은 TOP 곡선을 역투영한다.

투영된 원본 좌표는 일반적으로 이미지 x(y)2차식이 아니므로 텔레메트리에서 이를 구분한다. guidance_path_geometry=top_quadratic, guidance_top_coefficients=[a,b,c], guidance_start_top/target_top/target_edges_top/path_top를 추가한다. 기존 이미지 guidance_coefficients는 빈 배열이고 guidance_polynomial=projected_top_quadratic이다. 좌우 모두 observed이면 현재 경로 실선, 추정/유지 차선이 포함되면 추정 경로 점선으로 표시한다. 영상 좌표 경로이며 차량 조향 명령을 의미하지 않는다.

전체421개 회귀 통과(70.501초). 고정 시작점, TOP의 정확한 중점(비대칭 원근 포함), 단일2차식, 시작 접선, 원본 역투영, 추정 차선 사용, 표시 차선 누락 시 경로 생성 금지 및 표시 토글의 계산 유지 동작을 검사했다. 이전의 도로 복도/간격 기반 추종 계산은 제품 경로에서 사용하지 않는다. 아래 표시 도입 당시 기록은 과거 이력이다.

**표시 설정 → 중앙 추종선 표시 (청록색)** 체크로 원본 시점의 인식 결과 영상과 TOP에 계산된 중앙 경로를 표시/숨긴다. 좌우 분홍 차선 표시와 독립적이며, 숨겨도 전체 후처리가 켜져 있으면 계산·텔레메트리는 계속된다. 설정은 저장되며 연결 전 변경도 가능하다.

- 밝은 청록 실선: 현재 유효한 추종 경로.
- 어두운 청록 점선: 추정/유지 경로. 유효한 조향 명령을 의미하지 않는다.
- 표시할 경로가 없거나 전체 후처리가 꺼졌으면 그리지 않는다. 경로를 임의로 생성하지 않는다.
- 원본 RGB 수신 패널 및 '원본 RGB' 표시 모드는 순수 영상으로 유지한다. 오버레이는 원본 시점의 인식 결과 패널과 TOP에 표시한다.
- TOP은 도로·차선과 동일한 투영과 유효 영역 마스크를 사용한다. 좌우 경계가 덧그려지지 않도록 중앙 경로만 그린다.
